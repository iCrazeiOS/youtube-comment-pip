# YouTube Comments Auto PIP

A lightweight Chrome extension that keeps the YouTube video player visible in a compact floating view while you scroll through comments.

When you reach the comments and the normal player scrolls out of view, the player will move into a small picture-in-picture style window.

## Features

- Automatically opens the mini-player when you are reading comments.
- Returns the player to its normal layout when you scroll back up.
- Draggable floating player with persistent positioning.
- Resizable mini-player that keeps the video's aspect ratio.
- Dismiss button for the current video/page view.
- No setup or special browser permissions needed.

## Install from GitHub Releases

1. Open the [latest GitHub release](https://github.com/iCrazeiOS/youtube-comment-pip/releases/latest).
2. Download the `.crx` file from the release assets.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Drag the `.crx` file onto the extensions page.
6. Confirm the install prompt.

## Install from Source

Use this if you cloned the repository instead of downloading a release.

1. Clone or download this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the `youtube-comment-pip` directory.

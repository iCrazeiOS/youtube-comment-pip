# YouTube Comments Auto PIP

A small Chrome extension that keeps the YouTube video player visible in a compact floating view while you scroll through comments.

## Install locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `youtube-comment-pip` directory. 

## Behavior

- On YouTube watch pages, scroll down until the comments section is visible.
- When the normal player is no longer visible, it becomes a compact fixed player.
- Drag the handle above the mini-player to move it. Use the corner grip on the handle to resize it. The extension remembers both.
- Scroll back up until the normal player area is visible and the player returns to its normal layout.
